# Haier AC over IR for ESPHome

Climate component for Haier AC over IR for ESPHOME

Initially based on [ivanik7 esphome-haier-ac-ir](https://github.com/ivanik7/esphome-haier-ac-ir/tree/master)
Info on the [remote](https://github.com/TRuHa83/ESPHome_IR_Haier_Climate)

Due to the limited number of swing modes that ESPHome supports swing_mode used in wrong way.

- CLIMATE_SWING_OFF        - top
- CLIMATE_SWING_VERTICAL   - second from top to bottom
- CLIMATE_SWING_HORIZONTAL - third from top to bottom
- CLIMATE_SWING_BOTH       - full swing

Inspiration from [esphome-ykh531e-climate-component blog post](https://mazurov.dev/posts/esphome-ykh531e-climate-component/) and [github](https://github.com/smazurov/esphome-ykh531e)
